(versao corrigida - veja docs/Relatorio-de-Erros.pdf)

ESTRUTURA CORRETA (a pasta includes fica na RAIZ, nao dentro de assets)
Bistro/
  index.php              Painel de comandas
  produtos.php           Cadastro e edicao do cardapio
  database.sql           Tabelas e 10 produtos de exemplo
  database-migration-estoque.sql  Atualizacao do banco existente
  iniciar.bat            Atalho para rodar no Windows
  config/database.php    Conexao PDO
  includes/              funcoes.php, topo.php, rodape.php
  assets/style.css       Estilos
  docs/                  Relatorio de erros (PDF)

COMO RODAR NO VS CODE (Windows + XAMPP)
1. Abra o XAMPP e inicie o MySQL (o Apache so e necessario no metodo B).
2. Banco de dados:
     instalacao nova: phpMyAdmin > Importar > escolha database.sql.
     banco existente: selecione bistro_devops no phpMyAdmin e execute
     database-migration-estoque.sql uma unica vez.
     A migracao inicia o estoque existente em zero. Em Produtos, informe
     as quantidades reais antes de registrar novas comandas.
3. Metodo A (recomendado, funciona em qualquer pasta, inclusive OneDrive):
     duplo clique em iniciar.bat   OU   no VS Code: Ctrl+Shift+B
     o sistema abre em http://127.0.0.1:8000/
   Metodo B (Apache): copie a pasta Bistro para C:\xampp\htdocs\ e abra
     http://localhost/Bistro/
4. NAO use npm neste projeto: ele nao tem package.json (erro ENOENT).

PUBLICACAO NO INFINITYFREE
1. Crie o banco MySQL no painel e anote host, nome, usuario e senha.
2. Edite config/database.php com esses dados (o host NAO e localhost).
3. No phpMyAdmin selecione o banco, remova as linhas CREATE DATABASE/USE do
   database.sql e importe.
4. Envie o CONTEUDO da pasta para htdocs (index.php na raiz). Nao envie
   iniciar.bat.

NOTAS
- Numero da comanda = ID sequencial (pode haver saltos; e normal em SQL).
- O preco do item e copiado para a comanda (historico preservado).
- O estoque e controlado em unidades; cada comanda baixa o estoque automaticamente.
- Use o botao Imprimir pedido em cada comanda para imprimir somente aquele pedido.
- Produtos inativos nao aparecem em novas comandas, mas ficam no historico.
- Sem login: use apenas como demonstracao didatica, sem dados reais.
- Nao publique credenciais reais em repositorio publico.
